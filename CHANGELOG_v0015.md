# v0015

Точечный откат сломанной lifecycle-логики v0014 и перестройка senior hierarchy под подтверждённую parquet-разметку.

- Убран ошибочный принцип «W3-(2) consumed после пробоя W3-(1) high». W3-(1) high теперь замораживается, а рабочий W3-(2) low может re-anchor ниже на новом COMPLETE4H, пока strict origin цел.
- Добавлена проверка степени nested impulse относительно parent W1, чтобы микро-4H движения не перехватывали метку W3-(1).
- Добавлена lineage-логика: если новый «global W1» начинается от уже известного senior W2, это трактуется как W3-(1), а его коррекция — как W3-(2). Это исправляет класс GRAM/USOIL, который раньше ошибочно печатался как W2.
- BCH-reference фиксирует W3-(1) 317.70 и допускает re-anchor W3-(2) low без сдвига projection anchor; цели остаются 400.90 / 465.6664 / 570.4664 / 740.0328 при low 296.10.
- GRAM-reference: parent W2 1.286 -> W3-(1) 1.740 -> W3-(2) 1.460; цели 1.914 / 2.194572 / 2.648572 / 3.383144.
- Rating для crypto W3-(2) теперь ограничивается качеством COMPLETE4H recovery: 2/3 C4H не может получить >8.8; слабая 3/3 recovery только выше .618 не может получить >8.4. Это убирает искусственные 9.x из walk.
- /walk сохраняет один structure_id на parent W2 для W3-(2), поэтому re-anchor той же senior correction не становится новым fresh signal.
