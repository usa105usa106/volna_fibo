# v0024 — XAU/XAG market routing and TON/GRAM provenance

Дата: 05.10.2026. База: полный v0023. Объём ограничен запросом пользователя.

- Binance: добавлен отдельный клиент USD-M Futures для металлов. XAU/XAG обнаруживаются через `fapi/v1/exchangeInfo`, свечи обеих частот идут через `fapi/v1/klines`. Spot crypto и его Top-N не переключены на фьючерсы. USOIL недоступен, когда его нет в каталоге. XAUT не используется как замена золота.
- MEXC: XAG разрешается через каталог контрактов в официальный API-тикер SILVER_USDT. Вызова несуществующего XAG_USDT по умолчанию больше нет. Если биржа позднее перечислит точный XAG_USDT, он также поддержан.
- Ввод металлов с суффиксом USDT, подчёркиванием, дефисом или слешем канонизируется. Для MEXC добавлен явный псевдоним SILVER_USDT. Прочие криптовалюты нормализуются по-прежнему.
- Серебро использует существующую commodity-проверку свечей и не попадает в криптовалютный рейтинг. Постоянная пара Search XAU/USOIL сохранена, XAG добавляется ручным запросом.
- Snapshot/state для Binance металлов явно содержит `binance_futures`. Подзаголовок PNG/отчёта различает Spot crypto и Futures металлы; txt содержит рынок каждой строки. Заголовок дополнительной секции включает XAG, когда он запрошен. Колонки таблицы сохранены.
- GRAM: код загрузки истории не изменён. Подтверждены настоящие запросы официальных TON ZIP/CHECKSUM и существующая цепочка fallback MEXC. Для успешно восстановленной родной истории добавлена подпись TON→GRAM. Ошибки архива не дают подписи успешной загрузки.
- Версия приложения и Docker 0024. Внутренняя версия Elliott-детектора остаётся 0023: формулы и методология не менялись, массовый принудительный recount не нужен.

Добавлены 30 regression checks: выбор рынка/контракта, отсутствие USOIL, серебро MEXC, нормализация, две частоты/пагинация, повреждённые свечи, очистка HTTP при Reset, реальная цепочка TON ZIP с проверкой checksum, отказ источника, отображение происхождения. Итог полного прогона и ограничения — AUDIT_v0024.md.

Обновление: полный архив, прежний volume `/data`, `BOT_VERSION=0024`, rebuild. Reset не требуется. Для включения вновь доступного XAU Binance в автоматическое сопровождение запустить новый Search.
