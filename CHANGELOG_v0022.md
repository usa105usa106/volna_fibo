# v0022 — контроль зрелой W3 / кандидата W4

Дата: 04.10.2026. База: v0021; исходный проект происходит из v0018.

- Исправлен подтверждённый на ZEC дефект: перенос origin к старшему W2 больше не означает автоматическое объявление всей последующей пятичастной волны W3-(1). Общая проверка использует прежние D1/COMPLETE4H pivots, амплитуды и retracement, порядок точек, отсутствие overlap и правило длины третьей волны.
- Добавлена диагностика `W4 / PHASE_UNCERTAIN` («W4? · кандидат»). Она исключается из нового TOP-10 W2/W3-(2), не получает рейтинг входа, лимитные зоны и цели по формуле W3. Пять движений не доказывают единственность Elliott degree; формула W5 не введена.
- Track сохраняет наблюдаемую старшую стадию после перезапуска и потери старых свечей из окна; реагирует на закрытые 4H lows, новый high и intrabar overlap W1. Старое состояние того же цикла переводится в фазовую диагностику. Первый Track после обновления выполняет пересчёт старых версий по тем же тикерам; INVALID/RECOUNT не оживают.
- Добавлены 32 regression-сценария: реальные ZEC и INIT, пять контрольных активов, смена тикера/масштаба/дат, отрицательные варианты subdivision, сокращённая история, исторические cutoffs, upgrade, Track, SQLite и вывод таблицы.
- Добавлены неизменённые исходные ZEC/INIT parquet-строки и проверенная по официальным SHA256 H1-история Binance для ZEC. Fixtures остаются offline и не подменяют live-запросы.
- Версия 0022 согласована в настройках, Docker label, env-примере и replay. Формула Fibonacci и численные коэффициенты рейтинга не изменены. Исключений для ZEC, INIT, BCH или GRAM в проверке фаз нет.

Проверка: 294 теста; Ruff E9/F, compileall, Bandit, pip check проходят; pip-audit runtime lock не нашёл известных уязвимостей на момент запуска. Полный Ruff: 52 унаследованных замечания, новых нет. Replay: 302 инструмента, 188 W2/W3-(2), 2 кандидата W4, 55 NO_SETUP, 57 DATA_INCOMPLETE, 0 ошибок чтения.

В архив включены исходники, regression fixtures, AUDIT_v0022.md, обновлённая методология, логи и таблицы replay. На сервер/Coolify релиз автоматически не установлен.
