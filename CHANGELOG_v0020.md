# Changelog 0020

Адресное исправление ошибок 0019, обнаруженных после скриншота пользователя. Полная верификация текущей MEXC-разметки **не завершена**; подробности в `AUDIT_v0020.md`.

- Fresh detect ставит текущую коррекцию перед исторической завершённой структурой. Прежний приоритет W3-(2) над W2 применяется внутри одной lifecycle-категории.
- Наличие nested candidate больше не подавляет проверку W2 того же parent.
- Первая COMPLETE4H closing acceptance выше projection high сохраняется в JSON (`structure_evidence.projection_accepted_at`). Учитывается и свеча, на которой low появился до breakout close.
- Lock не исчезает после ухода acceptance-свечи за левую границу rolling history.
- Историческая структура подписывается `после W2` / `после W3-(2)` и сохраняет оставшиеся цели для сопровождения.
- Уже достигнутая T1 не получает повторный бонус в рейтинге после отката цены. Сохранены коэффициенты исходного score.
- Формула целей, численные senior/Fib thresholds, API clients, scheduler, commit/reset/retry не менялись.
- Добавлены 7 regression cases. На исходной 0019: 7 failed. На 0020: 7 passed.
- Полный suite: **229 passed**, 2485 dependency warnings. Ruff E9/F и compileall пройдены, Bandit — 0 findings; расширенный Ruff — 52 оставшихся замечания.
- Полный replay прежнего архива: 302 инструмента, 0 data errors; 40 изменённых результатов, включая 15 изменений anchors. Это не подтверждение правильности всех разметок. Diff результатов: `audit/replay_changes.json`.
- Версия и Docker label — 0020. При первом Track legacy-состояния 0018/0019 пересчитываются на тех же тикерах; сохранённые INVALID/RECOUNT не восстанавливаются.

BCH, DOGE, GRAM, XAU и USOIL на прежнем 42-дневном архиве сохранили прежние опорные точки. 0020 не подгоняет BCH 400.90 или USOIL 111.02 под ручную таблицу; вопрос правильного Elliott-импульса для спорных live результатов остаётся открытым.
